## О проекте

Это независимый дизайн-концепт, подготовленный как коммерческое предложение для бренда Zaga Zaga. Сайт показывает, как бренд может выглядеть в современном цифровом формате: ярко, динамично и удобно на любом экране.

Проект не является официальным сайтом Zaga Zaga и не означает сотрудничество или одобрение со стороны правообладателя.

## Что реализовано

- адаптивная вёрстка для компьютеров, планшетов и телефонов;
- интерактивный выбор напитка в первом экране;
- авторские макеты банок, созданные на HTML и CSS;
- плавные появления блоков и объёмные hover-эффекты;
- управление анимацией и поддержка `prefers-reduced-motion`;
- карточки вкусов, FAQ, контакты и ссылки на карты;
- семантическая HTML-разметка и доступная навигация с клавиатуры;
- автоматический production-деплой через Vercel.

## Визуальное направление

| Элемент | Решение |
| --- | --- |
| Настроение | свежее, энергичное, дружелюбное |
| Палитра | молочный фон, глубокий зелёный, мягкий лайм |
| Типографика | крупные акцидентные заголовки и спокойный основной текст |
| Движение | ненавязчивые появления, параллакс и лёгкий 3D-наклон |
| Продукт | стилизованные CSS-макеты без сторонних изображений |

## Технологии

```text
HTML5  ·  CSS3  ·  Vanilla JavaScript  ·  Vercel
```

Проект не требует сборщика, фреймворка или установки зависимостей.

## Локальный запуск

Откройте файл `dist/index.html` в браузере или запустите любой статический сервер:

```bash
npx serve dist
```

## Структура

```text
dist/
├── index.html      # содержимое и структура страницы
├── style.css       # дизайн, адаптивность и CSS-макеты
├── motion.js       # появления и интерактивные эффекты
└── experience.js   # переключение напитков и поведение интерфейса
```
